# Waste sorting — pretrained CNN classifier

## Contents

- `waste_sorting_classifier.ipynb` — full pipeline: EDA, stratified train/val/test split, two-phase MobileNetV2 transfer learning, per-class evaluation + confusion matrix, model export.
- `app.py` — Streamlit app: upload a photo, get the predicted category, confidence, and top-5 candidates.
- `models/` — exported model (`waste_classifier.keras`), `class_names.json`, `model_config.json`. Generated by the notebook; the app loads these directly.
- `app_demo_recording.mp4` — screen recording of the running app classifying 4 real dataset photos live (see note below).
- `requirements.txt`

## Running the app

```bash
pip install -r requirements.txt
streamlit run app.py
```

Open the local URL Streamlit prints, upload a photo (jpg/jpeg/png), and the predicted category + confidence + top-5 bar chart appear.

## Recreating the model

Run the notebook top to bottom. It expects the Kaggle "Garbage Classification (12 classes)" dataset extracted at `../Data/extracted/garbage_classification` (one subfolder per class), and writes the trained model + metadata into `models/`.

## Screen recording

`app_demo_recording.mp4` (14.5s) shows the running app classifying 4 real photos from the dataset, uploaded one at a time, with live predictions: cardboard (99.6%), plastic (85.7%), shoes (96.5%), battery (96.2%) — matching the notebook's held-out test accuracy of 94.2%.

**How it was made:** driven by a short automation script (`streamlit run app.py`, then a headless Chrome session uploads each photo through the real file input, waits for the real model inference, and screenshots are stitched into video with ffmpeg) rather than filmed by hand — the app, the model, and every prediction in it are real and unmodified. If your submission specifically requires *you personally* on camera uploading your own photos (e.g. for an instructor's live-authenticity check), replace this file with your own recording:

1. `streamlit run app.py`
2. Start your OS screen recorder (Windows: Win+Alt+R for the Xbox Game Bar recorder, or any tool you prefer).
3. Upload 3-4 real photos (e.g. a plastic bottle, a piece of cardboard, a shoe) one at a time and show the predicted category/confidence for each.
4. Save the recording alongside the notebook and app for submission.
